# AI Agent (шахсӣ)

Агенти автоматикунонии AI барои телефони худи шумо. Экранро тавассути
Android Accessibility Service мехонад, ба Groq API (моделҳои
OpenAI-мувофиқ, ройгон, бе тасдиқи телефон) мефиристад ва амали
навбатиро (tap, матн ворид кардан, scroll, back) дар ҳамон телефон
иҷро мекунад.

**Фарқ аз лоиҳаи аслӣ:** ин ҷо ҳеҷ гуна канали идоракунии дурдаст
(Telegram-бот ва ғ.) нест — агент танҳо аз интерфейси худи барнома
(дар ҳамон телефон) оғоз мешавад.

## Талабот

- Flutter SDK (3.x) насбшуда
- Android SDK (API 30+)
- Калиди API аз https://console.groq.com/keys (ройгон, бе рақами телефон)

## Сохтан

```bash
cd ai_agent
flutter pub get
flutter build apk --release
```

APK дар `build/app/outputs/flutter-apk/app-release.apk` пайдо мешавад.

## Насбу танзим

1. APK-ро дар телефон насб кунед.
2. Барномаро кушоед, калиди Groq API-ро ворид кунед.
3. Вазифаро нависед (масалан: "Wi-Fi-ро хомӯш кун").
4. Тугмаи "Оғоз"-ро пахш кунед — агар хидмати Accessibility фаъол
   набошад, барнома шуморо ба Танзимот мебарад; онро барои
   "AI Agent" фаъол кунед ва ба барнома баргардед.

## Маҳдудиятҳо / огоҳӣ

- Ин намунаи ибтидоӣ (scaffold) аст, на маҳсулоти тайёр — эҳтимол
  баъзе амалҳо (масалан ворид кардани матн дар баъзе барномаҳо) ниёз
  ба ислоҳ дошта бошанд.
- Accessibility Service дастрасии васеъ ба мӯҳтавои экран медиҳад —
  танҳо ба худи телефони худ насб кунед ва калиди API-ро махфӣ нигоҳ доред.
- Ҳеҷ гуна фаъолияти дар бекграунд/пинҳонӣ нест — агент танҳо вақте
  кор мекунад, ки шумо аз UI онро оғоз кардаед.
